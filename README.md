# Still With You

> Preserve their presence, not their authority.

Still With You is a consent-based AI Legacy Memory Agent being developed for the CockroachDB × AWS Hackathon — Build the Future of Agentic Memory.

The application allows a person to intentionally preserve memories, stories, values, experiences, advice, relationships, daily activities, and communication patterns. Authorized loved ones can later interact with an AI representation grounded in those preserved memories.

## Core Architecture

- Next.js / React — frontend
- CockroachDB Cloud — persistent memory layer
- Distributed Vector Indexing — semantic memory retrieval
- CockroachDB Managed MCP Server — agent interaction with persistent memory
- AWS Lambda — backend/agent execution

## Core Flow

Capture → Organize → Store → Retrieve → Reason → Explain
